# Nested Structure with Designated Initializers

## Author
M.Likitha

## Description
This program demonstrates initializing a nested structure
using designated initializers.

The Student structure contains a Marks structure. Specific
members of both structures are initialized using their
member names.

## Concepts Used
- Nested structure
- Designated initializers
- Structure members
- Nested member access
- Structure initialization

## How to Run

gcc nested_structure_designated.c -o nested_structure_designated

./nested_structure_designated
